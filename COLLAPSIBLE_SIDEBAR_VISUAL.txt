💾 STATE PERSISTENCE
─────────────────────────────────────────────────────────────────────────────

On Collapse:
  1. User clicks « button
  2. Sidebar adds .collapsed class
  3. Body adds .mefam-sidebar-collapsed class
  4. localStorage.setItem('mefamdev_sidebar_collapsed', 'true')
  5. CSS media query may override on mobile

On Page Reload:
  1. shared-sidebar.js checks localStorage
  2. Reads 'mefamdev_sidebar_collapsed' value
  3. If 'true', loads with .collapsed class
  4. Page renders in collapsed state automatically

On Mobile:
  1. Sidebar still slides in/out (@media max-width: 900px)
  2. Collapse preference NOT applied on mobile
  3. Desktop users see their preference when back on desktop
